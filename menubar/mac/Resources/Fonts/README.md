# Fonts

Static instances of the console's Commissioner and Martian Mono (SIL Open Font License 1.1, licences beside them), cut from `scripts/console-assets/fonts/*.woff2` at weights 400/500/600 (Commissioner) and 400/500 (Martian Mono). Same subset as the console; only the weight axis is fixed. Regenerate with fontTools `instancer` (see `menubar/mac/README.md`).
